## 1. `demo_S4_sampling.vcv` · 教学版（6 模块 / 8 线）

### 1.1 六个模块各是什么

| 模块 | 它是什么 | 打个比方 |
|---|---|---|
| **`Clocked`** | **节拍器 / 时钟**。按 BPM 稳定输出电脉冲 | 乐队里的鼓手在数拍子 |
| **`samplerx8`** | **8 槽采样播放器**。一格 = 一个声音，可调音量与左右声像 | 一台能装 8 张唱片的老唱机，每张一个音量旋钮 |
| **`VCF`** | **低通滤波器**。把声音里的"刺耳高频"磨掉 | 给声音盖一层纱，声音变柔 |
| **`Mixer`** | **混音器**。把多路声音合成一路 | 几个乐器一起进一个音响 |
| **`HostAudio2`** | **音箱输出**（左/右声道） | 最终发声的喇叭 |
| **`TextEditor`** | **说明牌**，机架上的文字解释 | 贴在机架上的便利贴 |

### 1.2 八条线分别连什么

**这一段是视频里最容易讲清楚的**，因为结构极简：

```
节拍器 ──四路分频──→ 采样器的前 4 槽（底鼓/军鼓/踩镲/拍手）
                        ↓ 8 槽混音成左右两路
                      混音器 ──→ 低通滤波（磨掉刺音）──→ 音箱
```

逐条列：

| 线 | 从 | 到 | 作用 |
|---|---|---|---|
| 1–4 | `Clocked` OUT 0/2/1/3 | `samplerx8` IN 0/1/2/3 | 底鼓每拍、军鼓反拍、踩镲八分、拍手点缀 |
| 5–6 | `samplerx8` OUT 16/17（混音） | `Mixer` IN 0/1 | 8 槽声音汇总成左右声道 |
| 7 | `Mixer` OUT 0 | `VCF` **IN 3**（音频入） | 送进滤波器 |
| 8 | `VCF` OUT 0 | `HostAudio2` IN 0 | 从左声道出声音 |

> ⚠️ **两个必须记住的端口号**（我查源码核实的，不是猜）：
> - `samplerx8` 触发口 = **IN 0–7**，混音输出口 = **OUT 16/17**（0–15 是各槽单独输出）
> - `VCF` 音频入口 = **IN 3**（IN 0/1/2 都被别的信号占用了）

### 1.3 录屏时可以现场拧的三个旋钮

| 拧哪里 | 效果 |
|---|---|
| `VCF` 的 **Cutoff** 拧大 | 变亮、采样声更"生" |
| `VCF` 的 **Cutoff` 拧小 | 变暗、几个采样融成一片 |
| 槽 3（踩镲）的 **Volume** 拧大 | 镲声变响 |

**这三个就够演示"修过效果"了**——尤其第一个，是最能体现"采样 ≠ 直接播"的地方。

### 1.4 "已经修过"体现在哪

机架里**没有一行是"原始素材直接播"**，我做了三处处理：

1. **滤波**：所有声音过一道低通，去掉合成噪声的毛刺，让 8 个采样听起来像**一个人**打的。
2. **音量平衡**：每槽音量都调过（表在 `SAMPLING-GUIDE` 同级的脚本里），
   除了底鼓 0.95，其余都压到 0.7 以下——不然一叠加就爆音。
3. **声像铺开**：踩镲偏右（0.62）、拍手偏左（0.38），
   拨弦偏右、贝斯居中——**立体声不是左右各一半，是有分工的**。

> 💡 **视频怎么讲这一段**：
> "这些采样都是我一个个算出来扔进去的。真正的'修'不是加了什么，
> 是**减**了东西——把那层刺耳的高频磨掉，再把几个声音的音量摆对位置，
> 让它们听起来像同一双手在打。"

## 2. `demo_S5_fullkit.vcv` · 大阵仗版（13 模块 / 20 线）

### 2.1 三层结构

| 行 | 内容 | 作用 |
|---|---|---|
| **行 0** | `Clocked` + `samplerx8 A`（鼓）+ `Mixer` + `VCF` | **鼓组打底** |
| **行 1** | `samplerx8 B`（旋律）+ `samplerx8 C`（和声）+ `Mixer` + `VCF` + `ADSR` + `VCA` | **音乐层** |
| **行 2** | 第三个 `samplerx8`（同 C） | 和声铺底 |
| **行 3** | `TextEditor` 说明牌 | 解释 |

**12 个采样槽全部装满**（8 鼓 + 4 旋律 + 4 和声中选 12），剩 `tom_high` / `rim` / `bass_F1`
在说明牌里标着"可随时替换"。

### 2.2 比 S4 多出来的两件事

**① 两条滤波**（`VCF_DRUM` + `VCF_MEL`）
鼓和旋律用**不同的滤波量**：鼓滤得更狠（0.40）显得扎实，旋律滤得少（0.55）保持清晰。
这是混音的基本手法——**不同声部走不同的路**。

**② 一条动态链**（`ADSR` → `VCA`）
`ADSR` 输出一个缓慢起伏的包络，接进 `VCA` 的音量控制口 —— 效果是**音乐在"呼吸"**：
声音轻轻被压低一点、再放开。这是 S4 没有的，也是"修过"的高级版。

> ⚠️ `VCA-1` 两个入口别接反：**IN 1 = 音频，IN 0 = 控制电压**。
> 我第一次接线就差点接反了，查 `PORTS.md` 才对。

### 2.3 录屏建议

- **S4 用于"讲解"**：结构简单，一屏能说完，观众看得清。
- **S5 用于"效果"**：一推上去就是一片完整的鼓 + 旋律，适合放在视频后半段当"成果展示"。

## 6. ⚠️ 存档：16:25 那次崩溃的根因（已修，留作教训）

第一版这两份机架**一加载就让 Cardinal 崩溃**（李 16:18–16:26 试了 6 次，
`%LocalAppData%\CrashDumps\` 留下 6 个 45.7 MB 转储）。

**定位办法不是猜，而是「和一份能正常打开的机架并排逐字段对比」**，抓到三处硬伤：

| 字段 | 错误写法 | 正确写法 | 后果 |
|---|---|---|---|
| `Clocked` 速度参数 | `0.463` | **`120.0`** | ★**主凶**：它收**绝对 BPM**，不是 0–1 小数。0.463 BPM 让内部时钟分频算出荒谬值 |
| 顶层 `version` | 整数 `2` | 字符串 `'2.4.1'` | 反序列化炸 |
| 模块 `version` | 整数 `2` | 字符串 `'2.1.0'` 等 | 同上 |

**修法（已固化进项目纪律）**：
造机架**一律从能正常打开的机架克隆模板**（`copy.deepcopy` 它的模块），
只改 `id` / `pos` / `params` / `data` ⇒ 版本号类型天然正确。
模板不够时去 `refs/examples/*.vcv` 与 `patches/Final Patch Work.vcv` 里找
（`VCF` / `Mixer` 就在后者里）。生成脚本：`tmp/fix_patches.py`。

**顺带记两条省时间的经验**：
- 别在 `.dmp` 转储上耗时间（压缩格式，字符串扫不出模块名）。
- PowerShell `Get-WinEvent` 查不到 Cardinal 的崩溃记录（应用日志是空的）。
- **最快的定位法：把崩的机架和一份能开的机架并排 dump 对比。**
