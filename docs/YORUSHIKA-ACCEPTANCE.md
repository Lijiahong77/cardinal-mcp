## 0. 这版是什么（11:25 融合版）

以李/对方在用的 **29 模块演奏版**为基底（含 8 小节录音：BASS + 三轨和声 +
KICK/SNARE/HAT 鼓 + RIFF），只做了两个选型替换，调音/接线/录音一律没动：

| 换什么 | 原文 | 换成 | 为什么 |
|---|---|---|---|
| 底鼓 | BassDrum9（TR909 电子底鼓） | **CR78**（Roland CompuRhythm 1978 模拟电路鼓） | 修羅鼓谱实证是原声鼓组；909 电子底鼓音色方向不对，CR78 温暖圆润是库里最贴原声的 |
| 混响 | Plateau（界面不直观） | **SurgeXTFXReverb2**（李自己 Final Patch Work 在用的 Surge XT 系） | 旋钮带名称+数值+预设选择器；参数等效映射保留对方的轻湿 12% |

鼓的驱动方式维持 0039 架构：**鼓节奏由 Expander 输出触发**（KICK/SNARE/HAT 轨的
GATE → 鼓模块），即鼓也录在循环里；鼓垫打的是鼓的第二声部（手动加花）。

## 1. 请重点听（这次的两个替换）

1. **底鼓音色**：从 909 电子底鼓换成 CR78 温暖模拟鼓——应该更圆、更接近真鼓。
   ⚠️ 如果听起来不对（太散/太轻/不像底鼓），**拧 CR78 面板上的 SELECT 旋钮**（0-6
   七个采样，现在用 01；03 是李在 helm_drums 里验证过的那个）
2. **混响**：Surge Reverb2 替代 Plateau，湿度和空间感与原来一致（12% 轻湿），
   界面上每个旋钮有名字，触控条上下控制它的混响运动

## 2. 可调参数（沿用 0039 的 SMK25 映射）

按李选定的 **Yorushika（ヨルシカ）** 风格做的「键盘即兴 + 自动伴奏」机架。两首代表曲拆成两个文件：

- **修羅模式**（`yorushika_shura.vcv`，已在你屏幕上）：C 大调 / **100 BPM** / 8-beat 摇滚鼓
  （909 底鼓 1&3 拍 + 军鼓 2&4 + 闭镲八分）/ 亮 pad
- **花模式**（`yorushika_hana.vcv`）：E♭ 大调 / **~78 BPM**【BPM 为待核实默认值】/ 轻鼓
  （底鼓 1/3 拍 + 闭镲四分）/ 柔 pad / 长混响

**核心不是写死的伴奏循环**：你弹的和弦通过 MiniArranger（昨天验收的那个）实时录成
4 轨循环——每轨一个独立音色（贝斯 / pad / 琶音 / 旋律），鼓自动走风格型。

## 2. 操作流程（三分钟上手）

1. 按 **Clocked 面板上的 RUN 键**（行 0 最左边大模块）→ 风格鼓点走起
2. 按 **MiniArranger 的 REC**（或键盘上的 REC 键）→ 弹 4 小节和弦 → 再按 REC 停
   - 和弦的每个音自动分到一轨：最低音=贝斯轨、中音=pad、中高=琶音、最高=旋律
   - 💡 键盘上开 **SC/CH 智能和弦**：按一个键就出完整和弦，一键铺满 4 轨
3. 按 **MiniArranger 的 RUN**（或键盘 PLAY 键）→ 你弹的织体开始循环
4. 在电钢层上即兴弹主旋律（你弹什么立刻出声，不走循环）
5. STOP 键 = 循环复位

## 3. 请重点听

1. **按 RUN 后鼓的风格**：修羅应该是 100 BPM 的行进摇滚感（底鼓 1&3、军鼓 2&4、闭镲八分）——
   快了/慢了拧旋钮 7
2. **录一段 4 轨和弦循环，然后在电钢层即兴**：听四轨织体（贝斯/pad/琶音/旋律）
   和你弹的主旋律是否分层清晰、不打架

## 4. 可调参数（旋钮 = SMK25 上排 8 个，第 1 层，别按 KNOB-B）

| 旋钮 | 控制 | 拧大 | 拧小 |
|---|---|---|---|
| 1 | 电钢明暗（滤波截止） | 更亮更脆 | 更闷更暖 |
| 2 | 混响尾巴 | 空间大 | 紧 |
| 3 | 鼓音量 | 鼓突出 | 鼓退后 |
| 4 | 贝斯音量 | 低频厚 | 薄 |
| 5 | pad 音量 | 铺底厚 | 薄 |
| 6 | 琶音音量 | 琶音突出 | 弱 |
| 7 | **速度（BPM）** | 更快 | 更慢 |
| 8 | 电钢余音 | 尾音长 | 短 |

其他物理控件：
- **触控条左右** = 弯音（±2 半音）
- **触控条上下** = 混响运动（松手自动回中，不会破坏声音——专门挑过）
- **鼓垫 1/2/3** = 开镲 / 通鼓 / DMX 打击乐（现场加花，打在自动鼓之上）
- ⚠️ **别按 KNOB-B / PAD-B**（切到第二层后 Cardinal 接不住）

## 5. 已知边界（本版）

- 军鼓仍是 SnareDrumN（Novation Drumstation 建模，电子军鼓方向）——全库盘点过没有更原声的军鼓模块，这是 Cardinal 的素材边界
- 混响是 **inline**（串在主输出后，所有声音包括鼓都过混响）——0039 架构如此。低频进混响通常不理想，如果不喜欢可以改成 send（鼓/贝斯撇掉）
- CR78 底鼓采样 01 是按文件大小+CR-78 面板首位推断的，未经耳朵验证——不对就拧 SELECT
- 备选架构（生成器版 `yorushika_shura/hana.vcv`）：Sequencer 自动鼓型兜底 + Plaits 琶音轨 + send 混响 + 低频不进混响，但**没有你录的这 8 小节**。想对比可以随时切
